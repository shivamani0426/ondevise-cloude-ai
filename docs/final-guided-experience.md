# Final guided experience

The real document workspace is now the default route. Simple review displays potential differences, matching extracted details, and uncertain relationships separately. AI is optional and accessible directly. Existing advanced tools and local-only privacy gates remain available. The redesigned layout uses responsive, accessible CSS without new assets or dependencies.

The engine retains its conservative scope. Agreement means a cited field matched, not authenticated records. Partial references are never verified identities. For paired conflicts, AI choices are narrowed to both compared quotations when available; incomplete selections are rejected rather than represented as evidence of both values.

Verification: existing unit and browser suite, additional agreement/partial-reference and AI-pair tests, production build and dependency audit. Real-device visual inspection and a fresh local AI comparison remain recommended after deployment.
